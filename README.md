\## Git Branches \& Collaboration



\### What is a Git branch?

A Git branch is a separate line of development where we can make changes without affecting the main branch. It is useful for safely working on new features or updates.



\### What is a Pull Request?

A Pull Request is a request to merge changes from one branch into another. It is used in teams so members can review and discuss changes before they are merged.



\### Git merge vs git pull

Git merge combines changes from different branches. Git pull downloads the latest changes from a remote repository and updates the local branch.
